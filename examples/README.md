# Illustrative examples, not an application

`sample-schema.csv` only demonstrates the input column names. Three rows **cannot** support the approved ML forecasting pipeline. Antigravity milestone 02 must generate a deterministic, explicitly synthetic daily CSV fixture with approximately 120 consecutive dates for each of three SKUs; it must pass through the **same real server endpoint** as user uploads.

`web.env.example` demonstrates local environment variable naming; production needs a real deployed backend HTTPS origin, not a placeholder. No API keys, customer data or credentials are included.
